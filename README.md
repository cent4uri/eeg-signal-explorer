# EEG Signal Explorer

Explore EEG recordings with filtering, visualization, and frequency analysis using publicly available neuroscience datasets. This beginner-friendly project demonstrates essential EEG signal processing techniques for neuroscience and biomedical engineering applications.

---

## Features

-  Load EEG recordings from open datasets
-  Visualize raw EEG signals
-  Apply band-pass and notch filtering
-  Perform frequency spectrum (FFT) analysis
-  Display power spectral density (PSD)
-  Interactive analysis using Jupyter Notebook

---

## Tech Stack

- **Python 3**
- **MNE-Python**
- **NumPy**
- **Matplotlib**
